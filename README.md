# be-chess

2025 마스터즈 백엔드GUI 탐색기 프로젝트

## Step 1
우선 텍스트 저장기를 만들어야 한다.  
먼저 터미널에 작성한 문자를 파일로 저장하는 프로그램을 만들어보자.  
그리고, 텍스트 파일의 내용을 읽어오는 프로그램도 만들어보자.  
그 다음에 Swing을 이용해서 GUI로 만들어보자.
### 간단한 사용법
1. 불러오기를 한다. (해당 경로에 파일이 없으면 메시지를 띄운다.)
2. 작성한다.  
3. 저장한다. (연결된 파일이 있으면 저장한다. 연결된 파일이 없으면 다른 이름으로 저장을 띄운다.)
### 주의할 점
기본적으로 프로젝트 파일 내의 files에 파일들이 저장되도록 했기 때문에 기본 Path가 files로 설정되어 있다.  
아마 추후 미션에서 절대 경로를 사용하도록 바뀌지 않을까 싶다.  

## Step 2 
탐색기를 구현해야 한다.  
Swing에서 화면을 좌측과 우측으로 나눠서 보여줘야 하는데, 각각 객체로 생성해서 객체 두 개의 정보를 보여주는 식으로 하면 될 것 같다.  
좌측이 부모 디렉토리, 우측이 현재 디렉토리로 구현할 것임.  
그래서 FileDirectoryList를 만들어서 좌측과 우측에 각각 생성해서 사용하면 될 것 같다.  
단순한 탐색기기 때문에 read나 write는 필요가 없을 것 같다.  

### 간단한 사용법
해당 디렉토리를 더블 클릭하면 오른쪽에 해당 파일의 하위 디렉토리가 뜨고, 왼쪽에는 해당 파일이 들어있는 디렉토리가 뜬다.  
마우스로 더블 클릭하거나, 버튼을 클릭하여 선택한 디렉토리를 바꿀 수 있고, 상하좌우 방향키와 엔터로 디렉토리를 선택할 수 있다.
